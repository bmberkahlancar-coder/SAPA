# SAPA v1 — Build Ready

Ini adalah proyek Flutter SAPA dengan konfigurasi Android dan `codemagic.yaml`.

## Build APK dengan Codemagic
1. Ekstrak ZIP.
2. Unggah seluruh isi proyek ke repository GitHub.
3. Tambahkan repository ke Codemagic.
4. Pilih workflow `sapa-android-debug`.
5. Jalankan build.
6. Download APK dari bagian Artifacts setelah build berhasil.

APK debug dapat digunakan untuk pengujian langsung di Android.
